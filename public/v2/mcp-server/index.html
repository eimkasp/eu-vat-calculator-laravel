Model Context Protocol

EU VAT MCP server

Give your AI assistant live EU VAT rates, VAT calculations, upcoming rate changes and VIES VAT number checks. Free, read-only and no sign-up.

  • Streamable HTTP
  • No sign-up or API key
  • Read-only

Connect your AI client

Choose your client and follow the steps. It takes about a minute.

  1. 1

    In Claude, open Settings → Connectors and choose Add custom connector.

  2. 2

    Name it EU VAT Info, paste the server URL and select Add.

  3. 3

    Turn EU VAT Info on for a chat from the tools menu, then ask about VAT.

  1. 1

    Run this command in your terminal:

    Terminal

    claude mcp add --transport http eu-vat-info https://vat.businesspress.io/api/mcp
  2. 2

    Start Claude Code and ask about VAT. Type /mcp to check the connection.

  1. 1

    Add this to .vscode/mcp.json in your project, or run MCP: Add Server from the Command Palette and choose HTTP.

    .vscode/mcp.json

    {
    "servers": {
        "eu-vat-info": {
            "type": "http",
            "url": "https://vat.businesspress.io/api/mcp"
        }
    }
}
  2. 2

    Open Copilot Chat in agent mode and ask about VAT.

  1. 1

    Add this to ~/.cursor/mcp.json, or to .cursor/mcp.json in a project.

    mcp.json

    {
    "mcpServers": {
        "eu-vat-info": {
            "url": "https://vat.businesspress.io/api/mcp"
        }
    }
}
  2. 2

    Check that eu-vat-info is enabled under Cursor Settings → MCP, then ask about VAT in chat.

  1. 1

    Add the URL as a remote MCP server using Streamable HTTP and no authentication. Most clients accept this configuration:

    JSON

    {
    "mcpServers": {
        "eu-vat-info": {
            "type": "http",
            "url": "https://vat.businesspress.io/api/mcp"
        }
    }
}
  2. 2

    ChatGPT connectors in developer mode, Windsurf, Zed and other MCP clients connect the same way.

What your assistant can do

Six read-only tools. Your assistant sees their descriptions and chooses the right one for each question.

  • All VAT rates

    get_all_vat_rates

    Every standard, reduced, super-reduced and parking rate for the EU and five other European countries.

    Parameters

    No parameters

    Try asking: Which EU country has the lowest standard VAT rate?

  • One country's rates

    get_country_vat_rate

    Current rates, currency and last update for a single country.

    Parameters

    • country string · required

    Try asking: What are the VAT rates in Austria?

  • VAT calculation

    calculate_vat

    Adds VAT to a net amount or extracts it from a gross amount at any rate type.

    Parameters

    • amount number · required
    • country string · required
    • mode string · optional
    • rate_type string · optional

    Try asking: How much is 1,250 euros plus German VAT?

  • Rate comparison

    compare_vat_rates

    Side-by-side rates for two to ten countries.

    Parameters

    • countries array · required

    Try asking: Compare VAT in Spain, Portugal and Italy.

  • Rate changes

    get_vat_rate_changes

    Recorded and upcoming rate changes with effective dates and sources.

    Parameters

    • country string · optional
    • upcoming_only boolean · optional
    • limit integer · optional

    Try asking: Which EU VAT rates are changing next?

  • VAT number check

    validate_vat_number

    Calls VIES

    Checks a VAT number in VIES and returns the registered name and address where the member state publishes them.

    Parameters

    • country_code string · required
    • vat_number string · required

    Try asking: Is LT100019070512 a valid VAT number?

Try it

Send a real request to the server from your browser.

POST /api/mcp

{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
        "protocolVersion": "2025-06-18",
        "capabilities": {},
        "clientInfo": {
            "name": "browser",
            "version": "1.0.0"
        }
    }
}

Questions

            

                                    

                        
                            What is MCP?
                            
                        
                        
The Model Context Protocol is an open standard that lets AI assistants use outside tools and data. Once connected, your assistant looks up live VAT data instead of relying on what it remembers.

                    

                                    

                        
                            Do I need an account or API key?
                            
                        
                        
No. The server is free and needs no sign-up. Fair-use limits keep it fast for everyone.

                    

                                    

                        
                            Is it safe to connect?
                            
                        
                        
Yes. Every tool is read-only: the server only returns VAT data and calculations. It cannot see your files or act on your behalf.

                    

                                    

                        
                            How current are the rates?
                            
                        
                        
Rates come from European Commission data and are refreshed daily. Every result includes the time the country was last updated.

                    

                                    

                        
                            Are the answers tax advice?
                            
                        
                        
No. The server returns reference rates. The right VAT treatment depends on the goods or services and the customer, so check important cases with a tax adviser or the national tax authority.
